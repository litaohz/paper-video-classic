# Paper Video Classic

Evidence-first paper explainers by [**Thomas Li**](https://github.com/litaohz).

> Keep the original paper visible. Bind highlights to exact source locations. Explain the idea beside the evidence.

![Classic source-linked explanation demo](docs/demo.gif)

[Watch the complete credential-free demo](docs/demo.mp4)

This is the public adaptation of the classic, pre-handwriting workflow: readable PDF source planes, progressive annotations, source-linked teaching cards, and deterministic video. It is not the newer brush/notebook production system and not an export of a private agent workspace.

## Try it

Python 3.10+ and FFmpeg/FFprobe on PATH are required. A GPU, API key, browser, and AI agent are **not** required for the demo.

```bash
git clone https://github.com/litaohz/paper-video-classic.git
cd paper-video-classic
python -m pip install -e .
python -m paper_video.cli demo --out out/demo
```

Open `out/demo/render/video.mp4`. The command generates an original demo PDF, finds real quote boxes, renders a 1080p/24fps clip, fully decodes it, and writes `verification.json` plus encoded annotation frames. It refuses to overwrite an existing output.

**The default demo is intentionally silent.** Its timings are labelled `authored_silent_demo`; they are not fabricated speech timestamps. The fixture is an authored explanation of this pipeline, not a published paper or a benchmark. No third-party paper is bundled.

## What is different

- **Evidence is the stage:** original PDF pixels stay visible; teaching panels are separate.
- **Grounded annotations:** exact text search supplies boxes. Missing, ambiguous or out-of-crop quotes fail instead of falling back to guessed coordinates.
- **One clock:** the optional narrated path binds highlights and captions to native speech word boundaries and verifies the audio hash.
- **Deterministic frames:** a frame is a function of time, with a seek-order check before encoding.
- **Honest verification:** actual decode, dimensions and frame checks, without claiming automated aesthetic or scientific approval.

## Use your own paper

Start with the `config.json` generated by the demo. Change `pdf`, the one-based `page`, top-left-coordinate `crop`, source label, exact quotes, and teaching text. The current small reference compositor shows **one selected page region per render**; render several clips for a multi-section paper. It is not a fully automatic literature-review agent.

```bash
python -m paper_video.cli quote --pdf paper.pdf --page 3 --text "a unique exact phrase"
python -m paper_video.cli render --config project/config.json --out out/section
```

Use a font you are licensed to use via `--font /path/to/font.ttf` for Chinese or other scripts. The portable English demo uses Pillow's bundled font. Scanned/image-only PDFs need an OCR stage; this release does not invent missing text coordinates.

## Optional narration

An Azure adapter is included in `adapters/azure`. It requires your own Azure Speech subscription and makes a paid service call only when explicitly run. It saves native word boundaries and a WAV hash, not credentials. See [pipeline.md](docs/pipeline.md) for setup and the generic manifest format. You can supply another provider's real boundaries in the same format.

```bash
python -m paper_video.cli render --config project/config.json --native audio/speech.json --out out/narrated
```

Changing the narration invalidates its timings. The renderer rejects text coverage or audio-hash mismatches.

## Agent workflow

Use [the classic skill](skills/paper-video-classic/SKILL.md) in your agent's skill directory. It teaches source selection, research-question-first explanation, claim/evidence alignment and production boundaries. For the companion paper-reading and script-structuring workflow (five-step cognitive path, benchmark walkthroughs, and visual storytelling), pair it with [**limu-paper**](https://github.com/litaohz/limu-paper):

```bash
# Clone with limu-paper included under skills/limu-paper:
git clone --recurse-submodules https://github.com/litaohz/paper-video-classic.git

# Or pull limu-paper into an existing clone:
git submodule update --init --recursive
```

A skill is guidance, not a claim that an entire paper can be understood or verified by one command.

The rendering CLI works without an agent. Hosted generation, automatic publishing, private-message delivery, account setup, personal schedules and voice-preference histories are deliberately excluded.
